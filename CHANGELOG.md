# Changelog

## 0.1.0 — 2026-10-25

First curated public release of the camera-to-MuJoCo course project.

- Preserve the default G1 stepping controller, standing and shadow modes, mapping editors and experimental X1/TWIST2 paths.
- Include pinned upstream model/policy provenance and third-party license files.
- Add a project overview, portable installation guide, architecture, evidence limits and contributor guidance.
- Publish a 24-slide course presentation with technical diagrams, editable charts and notes, excluding personal video and its poster bytes.
- Retain the complete optimization report, five figure sets, derived metrics, speaking notes and defense questions.
- Provide explicit public quick/full regression entry points. Keep test scratch files inside the project and make the regression package importable independently of Python's stdlib test package.
- Exclude environments, download fragments, credentials, personal camera captures and raw human landmark/field traces. Private-input regressions skip explicitly.

Pretrained models were not retrained by this release. Exact dance imitation, a curated imitation-learning dataset, autonomous imitation policy training, end-to-end latency measurements and physical robot deployment remain future work.
