# 验证方法、结果与复现范围

## 运行自动检查

```powershell
.\.venv\Scripts\python.exe scripts/run_checks.py
.\.venv\Scripts\python.exe scripts/run_checks.py --full
```

快速组覆盖映射与输入会话、质量门控、人物选择、标定、采样提示和状态文件。完整组增加站立物理、踏步与长时间阶段切换回归，耗时更长。脚本返回非零代表失败，跳过数量会明确列出。

本次发布的实际运行结果记录在 [release-validation.json](release-validation.json)。历史课设测试数量与本次公开版测试数量分开，不能直接套用旧的“90 个通过”。

2026-10-25 发布检查：完整组运行 76 个用例，74 个通过、2 个因私有现场输入未公开而跳过，失败和错误均为 0。另外，从 Git 暂存区导出不含本机模型下载和运行日志的干净源码副本，快速组 58 个用例全部通过。两轮都使用已有项目的 Python 3.14.7 依赖环境，没有声称在另一台电脑完成全新安装。

## 公开版可以复现什么

模型、已有策略、部署配置、来源提交、哈希、合成输入与机器人目标向量已保留。安装依赖后可以重新运行接口测试、合成物理测试和上游动作参考回放。

原始相机画面、人体关键点轨迹和现场输入 JSONL 不在公开仓库。与它们对应的历史数值可检查公开报告与派生数据，但无法只用公开文件完整重算全部现场指标。两个私有输入用例会明确跳过，不用合成数据伪装成现场复现。

端到端延迟、多操作者独立重复实验、带真实姿态标注的动态误差、行为克隆训练和实机验证尚未完成。
