# 公开材料范围

本仓库从独立仿真工程整理而来，原工作目录继续保留，公开版的整理不删除或覆盖原始项目。

## 已公开

- 仿真代码、Windows 入口、映射配置与 HTML 编辑器。
- G1、TWIST2、X1 模型及已有策略，随附上游来源、提交、哈希和许可证。
- 自动测试、合成输入、机器人电机关节目标回归向量和上游动作样例。
- 完整优化图表报告、派生数值、图表 PNG/SVG 和统计说明。
- 24 页公开版答辩 PPT、讲稿、20 问与排练导航。

## 保留在本机

- 原始真人视频、相机截图及其在 PPT 中的封面画面。
- 人体关键点轨迹、原始现场输入 JSONL、持续更新的状态与采样文件。
- `.venv`、下载碎片、完整第三方仓库、临时预览和重复历史答辩版本。
- 登录凭据、令牌、SSH 私钥、账号配置。

公开版 PPT 不仅去掉视频播放入口，也删除嵌入的视频与相机封面字节。其他技术图、图表和备注保留；第 13 页改为公开材料与本地演示说明。

图表中的历史实验结果来自原课设记录。公开派生数据中的本机工作区前缀已改为相对路径；数值与原始来源哈希保持不变。完整原始现场数据不在仓库，因此公开版不能完整重新计算所有历史现场指标。

运行程序后新生成的本地日志由 `.gitignore` 排除。提交问题或贡献前，请自行检查其中是否包含个人画面、人体轨迹或账号信息。
